# Marketing Campaign Performance Dashboard

An interactive Power BI dashboard analyzing 1,500 marketing campaigns
across 6 channels, 5 regions and 4 products (2025).

## Business Questions
- Which channels and regions give the best return on ad spend?
- Where do users drop off between impressions and conversions?
